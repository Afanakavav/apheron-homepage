## 📋 Specifiche Tecniche

### Foto Professionisti
- **Dimensioni consigliate**: 400x500px (ratio 4:5)
- **Formato**: JPG o PNG
- **Peso**: Max 200KB per ottimizzazione
- **Stile**: Foto professionali, sfondo neutro, abbigliamento formale

### Immagini ACB Group
- **Dimensioni consigliate**: 800x600px (ratio 4:3)
- **Formato**: JPG
- **Peso**: Max 300KB
- **Contenuto**: Foto delle convention e incontri ACB Group

### Logo DNV
- **Dimensioni**: 150x150px o superiore (SVG preferibile)
- **Formato**: PNG con trasparenza o SVG

### Hero Background
- **Dimensioni**: 1920x1080px o superiore
- **Formato**: JPG
- **Peso**: Max 500KB
- **Suggerimento**: Immagine professionale di ufficio, Prato, o astratta blu

## 🎨 Consigli per le Foto

1. **Foto Professionisti**:
   - Abbigliamento formale
   - Sfondo neutro (bianco/grigio chiaro)
   - Illuminazione uniforme
   - Espressione professionale ma amichevole
   - Ritratto verticale

2. **Coerenza Visiva**:
   - Stesso stile per tutte le foto professionisti
   - Colori che si integrano con la palette del sito (blu, bianco, grigio)

3. **Ottimizzazione**:
   - Usa strumenti come TinyPNG o ImageOptim
   - Mantieni alta qualità ma riduci il peso
   - Considera formato WebP per migliori performance

## 📝 Note

- Se un'immagine non è disponibile, il sito mostrerà automaticamente un placeholder
- Le immagini vengono caricate in modo lazy (solo quando visibili)
- Tutte le immagini devono essere ottimizzate per il web
